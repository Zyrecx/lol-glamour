Every feature

Install

  1. Download GlamourApp-win-Setup.exe.
  2. Run it. No admin needed.
  3. Glamour starts in the tray and docks beside the League client when it opens.

Updates install when you close Glamour, or as a notice, or not at all: your choice in Settings.

Privacy

Glamour runs on your PC and talks to the League client on your PC. It sends nothing about your account. With Help improve Glamour on, it sends error reports and usage counts with names and ids removed; turn it off in Settings. Exactly what is sent

Is this allowed?

Glamour uses the League client's local API and the game's Live Client Data, and looks at a few areas of the screen for the loading-screen and augment tags. It never reads or changes game memory or game files and never injects anything.

It shows only what the client itself shows, and auto-ban and auto-lock only do what you set. Riot does not support the client API for third-party apps, and Glamour is not approved by Riot. The client API is not allowed on the Korean server. Use it at your own risk.
